## Uplinx 2.1

**Faster to get going**
- A welcome screen on first start: paste a subscription or link right there, or take it from the clipboard, a QR code or a file.
- Copied a link before opening Uplinx? It offers to add it.
- Drop files (configs, subscriptions, QR pictures) onto the window to import them.
- New servers and freshly updated subscriptions are pinged right away.

**Servers**
- **Fastest** — tests the servers if needed and connects to the quickest one (also in the tray).
- Favourites: star servers from their menu; they show on top, in the Servers widget and in the tray.
- Server groups fold and unfold with a click.

**Connection**
- Reconnects by itself after the core stops, after the network changes (TUN) and after sleep.
- Kill switch (system proxy mode): if the connection drops, traffic is blocked instead of going around the VPN.

**Routing**
- "Where will a site go?" — type a site or IP and see whether it goes through the proxy, directly or is blocked, and which rule decides. Geosite and geoip lists are read straight from the geo databases.

**Everyday comfort**
- Tray menu with servers, connection mode and routing mode.
- Tooltips on every icon button.
- Keyboard: Ctrl+V import · Ctrl+N add · Ctrl+F search servers · Ctrl+1…6 screens · F5 test / update · Esc close.
- The window remembers its size, position and last screen; so does the mini window.
- Logs: search, pause and export to a file.
- Speed and ping widgets explain themselves when there is nothing to show yet.
- "What's new" shows clean text.

**Downloads**
- `Uplinx-2.1.0.msi` — installs for the current user, no admin rights needed.
- `Uplinx-2.1.0-portable-win64.zip` — unpack anywhere and run `Uplinx.exe`.
- `SHA256SUMS.txt` — checksums.
