## Uplinx 2.0.2 — design review

The whole interface now follows one Material 3 Expressive scale:

- **One set of corners everywhere:** 8 (chips, tags), 12 (inputs, menu items), 16 (list items, menus, banners), 24 (cards and widgets), 28 (dialogs), and pills for buttons and badges.
- **One set of spacings:** 4 / 8 / 12 / 16 / 24. Every screen has the same 24 px margins, and right edges line up on every page; scroll bars no longer cover the content.
- Home: the connect widget keeps its text well inside the card; **Add servers** and **Edit** sit flush with the widget grid.
- Settings rows use standard heights (56 / 72 px); routing rules, split-tunnel apps and server rows are evenly spaced, with controls centred.
- Screen titles sit on the same line on every page; log filters are aligned with the buttons next to them; the pin icon looks right.
