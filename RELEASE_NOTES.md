## MyProxy 1.1.0

Прокси-клиент для Windows в стиле Material You 3 Expressive на ядре Xray-core.

### Загрузка
- **MyProxy-1.1.0-setup.exe** — установщик (Java уже внутри, ставится без прав администратора).
- **MyProxy-1.1.0-portable-win64.zip** — портативная версия: распакуйте архив и запустите `MyProxy.exe`.

Ядро Xray, гео-базы и wintun скачиваются при первом подключении.

### Что нового
- **Импорт чего угодно:**
  - Clash/Mihomo YAML вместе с правилами (`PROCESS-NAME` на Windows работает);
  - sing-box JSON, JSONC, JSON-массивы ссылок;
  - пулы прокси `host:port:user:pass`;
  - вложенные подписки;
  - Xray JSON с **балансировщиками** и цепочками: такой конфиг запускается целиком.
- **Реальный пинг через ядро:** URL-тест каждого сервера во временном Xray, системные настройки не затрагиваются.
  - До 10 параллельных замеров, для больших списков 25.
  - Серверы, которые отвечали раньше, проверяются первыми.
  - У балансировщика показывается лучший участник.
  - Старое значение зачёркивается, пока идёт новый замер; пинг можно запустить из меню строки.
- **Серверы:**
  - сортировка по имени, пингу или последнему использованию;
  - **скрытие серверов**, которое переживает обновление подписки;
  - маскировка адресов для стримов;
  - флаги Twemoji.
- **Подписки:**
  - логотипы из `profile-logo`;
  - закрепление;
  - анонсы и ссылки сервиса чипами;
  - красная метка у истёкших подписок и исчерпанного трафика;
  - профиль маршрутизации от панели (совместим с форматом Happ);
  - выбор клиента для панелей: Happ, INCY или без маскировки.
- **Удобство:**
  - импорт **QR-кода с экрана**, из картинки в буфере обмена или из файла;
  - диплинки `myproxy://add/…` с подтверждением;
  - **мини-окно** поверх всех окон;
  - выбор приложений для правил маршрутизации.
- **Ошибки понятными словами**, технические детали по кнопке.
- IPv6 через туннель, статистика трафика за всё время, проверка обновлений и обновление в один клик.
